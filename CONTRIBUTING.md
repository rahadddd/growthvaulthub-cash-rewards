# Follow development

Open the [Pull requests tab](https://github.com/rahadddd/growthvaulthub-cash-rewards/pulls) and select the draft for the work you want to follow.

- Open **Commits** to see each update after it is pushed.
- Open **Files changed** to review the current changes.
- Read the pull request description for progress and remaining work.

Keep the pull request in draft while work is in progress. Mark it ready for review when the changes and available checks are complete.
